A quick note before you begin

CipherForge is an educational demo, not secure file storage. Don’t use confidential, sensitive, or irreplaceable files. It provides no professional key management, identity checks, authentication, or cloud storage. AES-CBC is shown for learning, not as a modern default; direct RSA only works for very small demonstration files.
